**AMOS 剪辑台是一款依托于智能体、高度自动化的桌面创作与剪辑软件**，核心主打 **「自动生成 · 自动取回 · 自动剪辑」** 一条龙体验。

如果你是第一次使用 AMOS，不需要自己一遍遍切网页、盯进度、手动下载素材再拖进剪辑软件——把你的智能体通过官方接口或 MCP 接进来，从云端 AI 出素材到本机整理成片，都可以交给智能体高度自动化跑通。

## 核心自动化特色

- **依托智能体，全流程高度自动化**：支持智能体通过**官方接口**或 **MCP** 接入 AMOS 剪辑台，直接替你调度整个创作流程，告别重复繁琐的人工操作。
- **自动生成**：智能体可以直接控制云端任务，按你的想法生成 AI 素材，不用人工守在电脑前逐个提交。
- **自动取回**：云端生成完成后，成品会**自动落盘到你的本地电脑**，无需手动下载或逐个取回，打开本机文件夹就能直接使用。
- **自动剪辑与代码动效包装**：落盘到本机的素材支持**一键导入剪辑工作台**，交给智能体自动剪辑；智能体还可以依靠自身能力做可视化代码剪辑和代码动效包装——比如**用代码直接给镜头加字幕、调音量，你能在剪辑台里实时看到结果**。

## 更多功能

- **视频逆向分析**：帮你把一条参考视频拆开看懂——从镜头节奏、画面编排、剪辑手法到字幕表达逐段拆解，提炼出可直接借鉴的创作思路，方便你后续让智能体参考这些规律生成素材和自动剪辑。

## 开放计划

- **剪辑功能计划面向所有用户开放，目前剪辑功能尚未完全开放**；完整开放节奏与客户端发布请以本仓库后续更新为准。
- 现阶段，智能体已可以依靠自身实际能力完成可视化代码剪辑与代码动效包装，例如通过工单给镜头加字幕、调音量，并在剪辑台里直接查看效果。

## 工作流程一览

1. **接入智能体**：通过官方接口或 MCP 把你的智能体连接到 AMOS 剪辑台。
2. **自动生成**：由智能体控制云端任务，自动完成 AI 素材生成。
3. **自动取回**：生成好的内容自动落盘到本地电脑，无需手动取回。
4. **自动剪辑与包装**：本机素材一键导入剪辑工作台，由智能体用代码给镜头加字幕、调音量或完成动效包装，你能在剪辑台里直接看到结果（剪辑功能计划面向所有用户开放，目前剪辑功能尚未完全开放）。
